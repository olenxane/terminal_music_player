# MP 渲染器（renderer/）

把终端音乐播放器的实时画面渲染到一个**独立的桌面透明窗口**里：无边框、背景透明度可调、
可拖拽、可通过托盘一键锁定为鼠标穿透。渲染器以 **ConPTY 伪终端子进程**方式运行播放器，
用 pyte 还原终端画面，与播放器**零代码耦合**——播放器代码怎么改，重启子进程即加载新版。

```
┌──────────────┐  ConPTY(160×40)   ┌─────────────────┐
│  播放器子进程  │ ──ANSI 输出流──▶ │ pyte 虚拟终端模型 │
│ python main.py│ ◀──键盘 VT 序列── └────────┬────────┘
└──────────────┘                            │ 字符网格快照
                                   ┌────────▼────────┐
                                   │ Qt 透明窗口逐格绘制│ ← 托盘：锁定/透明度/重载
                                   └─────────────────┘
```

## 安装与启动

```bash
pip install -r renderer/requirements.txt   # PySide6、pywinpty、pyte、PyYAML
```

- 双击 `启动渲染器.bat`（pythonw 启动，无黑色控制台窗口），或
- `python renderer/main.py`

关闭程序：托盘图标右键 → 退出（会优雅退出播放器并保存窗口状态）。

## 操作

| 操作 | 方式 |
|---|---|
| 移动窗口 | 解锁状态下按住左键拖动，位置自动记忆 |
| 锁定（鼠标穿透） | **左键单击托盘图标**，或托盘菜单勾选"锁定"；锁定后所有点击穿透到下层窗口 |
| 解锁 | 再点一次托盘图标 |
| 调背景透明度 | 托盘菜单"背景透明度"滑杆，或窗口内 **Ctrl+滚轮** |
| 键盘控制播放 | 点击窗口获得焦点后，按键原样转发给播放器（space/n/p/←→/↑↓/s/q…，Ctrl+C 也等价 q） |
| 重载播放器 | 托盘菜单"重载播放器"；改播放器源码默认也会自动重载 |
| 退出 | 托盘菜单"退出" |

## config.json 字段

`player`：

| 字段 | 默认 | 说明 |
|---|---|---|
| `cwd` | `".."` | 播放器项目根目录（相对 renderer/ 或绝对路径） |
| `command` | `["python","main.py"]` | 启动命令；`python` 会被替换为渲染器所用解释器 |
| `player_config` | `"config.yaml"` | 播放器配置文件（用于推导窗口尺寸） |
| `graceful_key` | `"q"` | 优雅退出键（重载/退出时先发它，超时才强杀进程树） |
| `auto_reload` | `true` | 监视源码变更自动重启子进程；启动 10 秒内崩溃不自动重拉（防语法错误死循环），保存修复后或托盘手动重载 |
| `watch_interval_sec` / `watch_debounce_sec` | 2 / 1.5 | 轮询间隔与防抖 |
| `watch_globs` | `["mp/**/*.py", ...]` | 监视的文件模式（相对播放器根目录） |

`window`：

| 字段 | 默认 | 说明 |
|---|---|---|
| `cols` | `"auto"` | 列数；auto = 播放器 config.yaml 的 `playback.ui_width` |
| `rows` | `"auto"` | 行数；auto = 主界面行数 `3 +（频谱开启时 1+height）`；也可固定数字（此时超出部分像真实终端一样裁剪） |
| `pty_rows` | `40` | 伪终端总行数（窗口 `rows=auto` 时内容变高窗口自动增高，上限为此值） |
| `font_family` / `font_size` | Cascadia Mono / 12 | **需与你的终端字体一致**，像素尺寸才能和终端渲染对齐 |
| `fg_color` / `bg_color` / `bg_opacity` | — | 默认前景/背景色与背景不透明度（0.05~1.0，仅背景半透明，文字不受影响） |
| `always_on_top` | `true` | 窗口置顶 |
| `locked` / `x` / `y` | — | 运行状态自动回写，无需手改 |

## 尺寸如何计算（与终端一致）

初始化时：`cols/rows` 从播放器 config.yaml 推导 → 用 `font_family+font_size` 的
QFontMetrics 实测单元格像素 → 窗口像素尺寸 = `cols×cell_w × rows×cell_h`，
伪终端尺寸同步设为该网格。只要 config.json 里的字体与终端所用一致（Win11 Terminal
默认即 Cascadia Mono 12），窗口高度就与终端中渲染的高度一致。

## 已知限制

- 播放器必须通过标准终端协议输出（本项目用 rich，天然满足）；若未来换成完全不同的 UI 技术，需同步调整 pyte 还原层。
- 中文输入法向选择器搜索框输入文字依赖控制台输入编码转换，个别生僻字可能显示异常。
- 每次重载会遗留一个阻塞在已退出管道上的守护线程（pywinpty 阻塞 read 的已知行为），无功能影响。
